# GigaLab

Source for [GigaLab](https://gigalab.cloud), a personal technical blog focused on cloud, hybrid infrastructure and real-world troubleshooting.

## Local structure

- `_posts/` contains Markdown articles.
- `_layouts/` contains the custom Jekyll layouts.
- `_includes/` contains shared header and footer components.
- `assets/css/style.css` contains the custom visual design.

## Publishing

The site is published with GitHub Pages from the `main` branch.
